# ADR-0004: loopback HTTP-сервер на стандартной библиотеке

- Статус: принято
- Дата: 2026-09-23

## Контекст

Viewer должен работать локально на чистой машине хакатона. Сервер нужен только для ассистента и
досье; добавление web-фреймворка увеличило бы зависимости и риск воспроизводимости. Даже loopback
endpoint может быть атакован чужой web-страницей через DNS rebinding или простой cross-origin POST.

## Решение

Использовать `ThreadingHTTPServer`, привязанный только к `127.0.0.1`. Проверять `Host`, допустимый
`Origin`, требовать `application/json`, ограничивать размер тела и длину вопроса, валидировать GID.
Не добавлять CORS. Статический viewer остаётся одним автономным HTML-файлом без CDN.

## Последствия

- Сохраняются нулевая новая runtime-зависимость и одинаковое поведение Windows/Linux.
- Это локальный демонстрационный сервер, не production deployment с TLS/auth/rate limiting.
- При переносе handler в `gm/services/http.py` security checks переносятся без переписывания и
  защищаются существующим HTTP-тестом.
