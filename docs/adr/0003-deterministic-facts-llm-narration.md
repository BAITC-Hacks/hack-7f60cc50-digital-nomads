# ADR-0003: факты детерминированы, LLM только формулирует

- Статус: принято
- Дата: 2026-09-23

## Контекст

AML-аналитику нужны воспроизводимые роли, метрики и основания. LLM удобна для естественного языка,
но не должна назначать роль, менять приоритет или придумывать KYC-атрибуты и участников.

## Решение

Все факты рассчитываются пайплайном и разрешёнными функциями графа. LLM выполняет tool calling и
формулирует текст только по их результатам. Каждый GID ответа сверяется с вопросом и результатами
tools. В досье факты имеют идентификаторы `[F#]`; ссылки и GID LLM-текста проверяются, при ошибке
разрешён один раунд исправления, после чего текст явно помечается непроверенным. Без API-ключа
работает детерминированный fallback.

## Последствия

- Продукт остаётся локально работоспособным без LLM и сети.
- Grounding является частью ответа API и UI, а не скрытой эвристикой.
- Провайдер LLM можно заменить без изменения расчётной методологии.
- Новая функция ассистента сначала реализуется как детерминированный graph query с тестом.
