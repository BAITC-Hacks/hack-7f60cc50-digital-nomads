# Трассировка требований HackAlem «Граф денег»

Дата проверки: 2026-09-23. Источник чисел — фактический прогон на `data/*.parquet`, а не значения из README.

## Как воспроизвести аудит

```bash
python run.py --data data --out out
python tests/test_methodology.py
python tests/test_pipeline.py
python tests/test_assistant.py
python tests/test_serve.py
python tests/test_investigate.py
rg -n --pcre2 "(?<!\d)\d{15,}(?!\d)" gm run.py serve.py investigate.py
```

Фактический прогон завершился за **10,82 с** и напечатал
`схема выгрузок: OK (nodes_roles=2248, clusters=45, top_nodes=30)`.
Машиночитаемые доказательства сохранены в `out/run_report.json`, человекочитаемые — в
`out/report.md`. Проверка схемы непосредственно читает созданные CSV, а не объекты в памяти
(`gm/export.py:47-84`). Команда поиска 15+-значных литералов завершилась с кодом 1 и без
совпадений, то есть таких литералов в проверяемом production-коде нет.

## 5. Сверка контрольных чисел из примечания ТЗ

- `pass_through > 1`: **354** узла (`out/run_report.json → data_quality.pass_through_gt_1`).
- `0.8 ≤ pass_through ≤ 1.2`: **72** узла (`data_quality.pass_through_0_8_to_1_2`).
- Слабосвязные компоненты edge-induced графа: **16** (`data_quality.weak_components_with_edges`).
- Базовый Louvain из примечания ТЗ — неориентированная проекция с сырым весом суммы,
  `resolution=1`, `seed=42`: **8** сообществ с более чем одним seed
  (`gm/io.py:114-125`, `data_quality.baseline_louvain_multi_seed`).
- Рабочий Louvain проекта использует `log1p(sum_kzt)` и поэтому закономерно даёт **9** сетевых
  сообществ с более чем одним seed. Значение **10** в сводке CSV включает ещё строку
  `cluster_id=0`, где вместе сгруппированы **19 изолированных seed**; это не Louvain-сообщество
  (`out/run_report.json → methodology_checks`). Различие с контрольными 8 объясняется методом
  взвешивания, а не расхождением входных данных.

Таким образом, все обязательные пункты закрыты; ограничения датасета не скрыты и отражены как
явные проверки и оговорки, а не как недоказанные выводы о клиентах.
